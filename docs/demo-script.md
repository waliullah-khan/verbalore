# Demo script (Loom, about 4 minutes)

Run `npm run dev` and `npm run worker` first. Close other heavy apps so the render is quick. Have a take recorded as a backup.

1. **0:00 The problem (15 s).** Landing page. One sentence: everyone knows they should post video, nobody has the time.
2. **0:15 Today (45 s).** Open the demo workspace. Click through two tabs, for example GTM and Real estate, to show that ideas, formats and edit themes change per use case. Open an idea: evidence, the reference Jev picked and its breakdown, the script.
3. **1:00 The email (15 s).** Settings, send today's email. Show the digest with its "Make this video" button.
4. **1:15 Studio (45 s).** Record 20 to 30 seconds with the teleprompter. Show speed and size, pause with space, then "Use this take".
5. **2:00 The edit (40 s).** Library. The video appears as "Editing". While it renders, open the Signals page. When it is ready, play it and point out a graphic on every scene.
6. **2:40 Post (20 s).** Open "Post it", pick platforms, post. Say clearly if posting is simulated.
7. **3:00 Signals (60 s).** Scan accounts (or show results already found). Open a real signal such as a funding round with its source link. Add a custom watch phrase. Make a video note for a contact: the script is written from the signal, record it, then show the share page and the view count. Mention the app will not email an `example.com` sample contact.
8. **4:00 Close (10 s).** Brain and Settings in one breath: it writes only from what you gave it, and the connections page shows what is live.

If a live source is slow, say so and move on. Sample data is badged in the app.
